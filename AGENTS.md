# Repository instructions

Read every policy in [`.policies/`](.policies/0001-compliance.md) before working in this repository.
Follow [0013 - Development workflow](.policies/0013-development-workflow.md) for each new change,
including its discovery, fresh-agent handoffs, implementation, acceptance, and publication gates.

Use the applicable [project skills](.github/skills/README.md) to carry out those procedures.
Both discovery sessions require [glacier-interview](.github/skills/glacier-interview/SKILL.md);
the technical session still requires a fresh agent context and prior epic approval.

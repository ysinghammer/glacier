# Repository instructions

Read every policy in [`.policies/`](.policies/0001-compliance.md) before working in this repository.
Run `pnpm run ci` after every change to verify that all tests, linting, formatting, and documentation checks pass.
For all temporary artifacts like plans or scripts use the `./.plan` directory.
If you create code, create commits for each logical group of changes.
Commits must follow conventional commit format.

# Request handling

Safe transport values and explicit listener ownership let applications inspect normalized
credentials without exposing mutable Node handles. The phase-05 request pipeline is described
in the [package README](../../../README.md); hardened transport lifecycle/OpenAPI work is not claimed.

| Contract                 | Preconditions, action and observable outcome                                                                                                                                                                     | Runtime evidence                                                                                                                                                         |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Success envelopes        | Construct DTO/array/noContent values; valid fields are snapshotted and emitted, invalid statuses/framing/injection/fabrications fail safely                                                                      | [HttpResponses](HttpResponses.test.ts), [MinimalServer](MinimalServer.test.ts)                                                                                           |
| Cookie fields            | Construct defaults, explicit attributes and clear values; separate fields preserve opaque values, copy expiry dates and enforce scope/security syntax                                                            | [HttpCookies](HttpCookies.test.ts), [HttpResponses](HttpResponses.test.ts)                                                                                               |
| Normalized requests      | Send real HTTP fields/targets through an approved authentication hook; getAll preserves occurrences, query/path/cookies remain safe/readonly and request IDs ignore callers                                      | [RequestNormalization](RequestNormalization.test.ts)                                                                                                                     |
| Minimal lifecycle        | Import/create/listen/close explicitly; no listener on import/create, actual port-zero address, observable startup failure and idempotent stop without restart                                                    | [MinimalServer](MinimalServer.test.ts)                                                                                                                                   |
| Prepared routing         | Register all five verbs in different orders; lexicographic static precedence, trailing-slash equivalence, immutable metadata, inheritance and invalid/orphan/duplicate contracts are enforced before listening   | [Routing](Routing.test.ts), [MinimalServer](MinimalServer.test.ts)                                                                                                       |
| HEAD and OPTIONS         | Invoke real GET/HEAD/OPTIONS/unknown methods on known/unknown paths; full HEAD pipeline retains headers/length with zero body bytes on all outcomes, stable Allow and no authentication on OPTIONS               | [HeadAndOptions](HeadAndOptions.test.ts), [ExpectContinue](ExpectContinue.test.ts)                                                                                       |
| Authentication           | External hook is called once before protected body checks, public routes skip it; missing IDs have 401 challenge, invalid results have safe 500 diagnostics, incompatible UserId declarations fail before listen | [Authentication](Authentication.test.ts), [MinimalServer](MinimalServer.test.ts), [HeadAndOptions](HeadAndOptions.test.ts)                                               |
| Explicit binding         | DTO/direct binders expose actual normalized values; textual coercion and nested singleton arrays are query-only, JSON is constructor-free/noncoercing, missing/empty direct values stay distinct                 | [RequestBinding](RequestBinding.test.ts), [Authentication](Authentication.test.ts)                                                                                       |
| Required body and bounds | Real UTF-8 JSON/+json input succeeds; empty/malformed/nonobject/media/compression/unbound/schema failures are safe, declared/chunked excess and incomplete receive bounds cannot become success                  | [RequestBinding](RequestBinding.test.ts), [ExpectContinue](ExpectContinue.test.ts)                                                                                       |
| Strict output            | Declared void/204 and repeated status alternatives work; mismatches/plain/unsafe JSON/cycles/accessors fail before custom headers commit, diagnostics expose path/code only                                      | [ResponseContracts](ResponseContracts.test.ts), [MinimalServer](MinimalServer.test.ts), [HttpResponses](HttpResponses.test.ts), [RequestBinding](RequestBinding.test.ts) |

| Problem privacy          | Send controller/auth/output/routing failures; only invocation errors map, 401 retains challenge, RFC 9457 fields correlate IDs without exception or schema values                                                | [ProblemDetails](ProblemDetails.test.ts), [RequestBinding](RequestBinding.test.ts), [ResponseContracts](ResponseContracts.test.ts)                                       |

[ReadonlyRequests](../../contracts/ReadonlyRequests.test-d.ts) and
[DecoratorBindings](../../contracts/DecoratorBindings.test-d.ts) are type-only checking,
not runtime coverage. [CompiledBindings](../../data/compiler/CompiledBindings.ts) uses
genuine legacy compiler emissions and public-root distribution APIs, executed by Authentication.
[ErrorsAndLogging](../../contracts/ErrorsAndLogging.test-d.ts) verifies erased error/log/registration
contracts separately. [CompiledErrors](../../data/compiler/CompiledErrors.ts) proves genuine mapping
and exclusion decorators, executed by ErrorMappings. Hardened transport lifecycle and OpenAPI remain deferred.
